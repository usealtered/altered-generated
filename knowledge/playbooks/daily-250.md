# Daily $250 playbook

Goal: at least one $250 reservation deposit per day.

## Morning

1. Text `metrics` via iMessage
2. Open early-access page; confirm checkout live
3. Send 10 personal outreaches (warm network first)
4. Post one sharp pain-led note (where ICP already is)

## Midday

1. Follow up any clicked / replied leads
2. Offer deposit link in first serious reply
3. Log leads via `lead ...` if they come in sideways

## Evening

1. `metrics` again — if < $250, do one more conversion push
2. `remember` what objection blocked closes
3. Prompt Cursor: fix the highest-friction step in the funnel
